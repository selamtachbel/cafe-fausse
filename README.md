# Cafe Fausse

Cafe Fausse is a full-stack web application developed as a software engineering project.

## Technologies Used

### Frontend
- React
- JavaScript
- HTML
- CSS

### Backend
- Python
- Flask
- SQLAlchemy
- REST APIs

### Database
- Relational database

## Features

- Full-stack frontend and backend integration
- REST API communication
- Database operations using SQLAlchemy
- Responsive web interface
- Application debugging and error handling

## Project Structure

- frontend/ – React frontend application
- backend/ – Flask/Python backend application

## Skills Demonstrated

- Full-Stack Web Development
- React
- Python
- Flask
- SQLAlchemy
- REST API Development
- Database Management
- Git and GitHub
